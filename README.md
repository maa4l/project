# Animal Shelter API (Веб-сервис приюта для животных)

Учебный full-stack проект, представляющий собой веб-приложение для автоматизации работы приюта для животных. Клиенты могут просматривать картотеку питомцев и подавать заявки на их адопцию, а администраторы — управлять каталогом и обрабатывать заявки.

## Технологический стек
*   **Backend:** Python, FastAPI, SQLAlchemy, PostgreSQL, JWT (авторизация).
*   **Frontend:** React (Vite), React Router, Axios.
*   **Инфраструктура:** Docker, Docker Compose, Nginx.

## Основные возможности
*   **Ролевая модель (RBAC):** разделение на `Client` и `Admin`.
*   **Полный CRUD** для сущностей «Животные» и «Заявки на адопцию».
*   **Бизнес-логика:** при одобрении заявки статус животного автоматически меняется на «Зарезервировано».
*   **Безопасность:** хэширование паролей, защита эндпоинтов с помощью JWT-токенов.
*   **Современный UI:** адаптивный интерфейс на React.
